## 二、源文件功能说明

### 1. main.c — 主程序

| 函数/模块 | 说明 |
|-----------|------|
| `main()` | 系统入口：初始化→主循环。初始化HAL/时钟/外设/OLED/DS18B20/PID/BTS7960/UART/RTC后进入while(1)主循环 |
| `Display_Splash()` | 显示启动画面"Bio-Incubator System v1.0"，持续2秒 |
| `Display_Update()` | 每200ms刷新OLED：标题、当前温度、目标温度、运行状态、PID输出、系统时间 |
| `Alarm_Check()` | 三段式智能报警：启动免扰(10min)→偏差≤2℃正常→偏差>2℃且卡住60s报警 |
| `ProcessKey(uint8_t key)` | 按键处理状态机：`*`键设置/退格，`#`键确认/启停，数字键输入 |
| `UART_SendData()` | 每秒串口上报：T,SET,PID,HT,CL,RUN |
| `ProcessUartCmd()` | 解析上位机命令：SET:x.x, STOP, STATUS |
| `SystemClock_Config()` | 系统时钟配置：HSE 8MHz→PLL→72MHz |

**关键宏定义：** `CONTROL_CYCLE_MS=200`, `USB_REPORT_CYCLE=1000`, `TEMP_MIN=5.0`, `TEMP_MAX=50.0`, `TEMP_DEFAULT=37.0`, `ALARM_TEMP_HIGH=2.0`

**系统状态枚举：** `SYSTEM_STATE_IDLE`, `SYSTEM_STATE_RUNNING`, `SYSTEM_STATE_SETTING`, `SYSTEM_STATE_ALARM`

---

### 2. pid.c — PID控制器

| 函数 | 说明 |
|------|------|
| `PID_Init()` | 初始化PID参数(Kp,Ki,Kd,Ts,限幅)并清零内部状态 |
| `PID_Reset()` | 复位PID：清零积分、历史测量值、输出 |
| `PID_Calculate()` | 执行一次位置式PID计算，返回控制量[-100,+100] |

**算法特性：**
- 位置式：u(k)=Kp·e(k)+Ki·Σ[e(j)·Ts]-Kd·[y(k)-y(k-1)]/Ts
- 积分分离：\|e\|>3℃时Ki=0
- 微分对测量值：d_term=-Kd·[y(k)-y(k-1)]/Ts
- 独立积分限幅：integral_limit=100×0.8/Ki
- 抗积分饱和：输出限幅时反方向修正积分

**参数值：** Kp=15.0, Ki=0.8, Kd=2.5, Ts=0.2s, limit=±100

---

### 3. control.c — BTS7960 H桥驱动

| 函数 | 说明 |
|------|------|
| `Control_Init()` | 启动TIM3_CH1/CH2 PWM输出，初始占空比0 |
| `Control_ProcessOutput()` | PID输出→PWM映射：加热(>+5%)/死区(±5%)/制冷(<-5%) |
| `Control_Stop()` | 停止所有PWM输出，复位状态 |
| `Control_SetPower()` | 直接设置BTS7960输出模式与占空比 |

**控制区段：** PID>+5%→加热(PWM=|u|%)；-5%≤PID≤+5%→停止；PID<-5%→制冷(PWM=|u|%)

---

### 4. ds18b20.c — DS18B20温度传感器驱动

| 函数 | 说明 |
|------|------|
| `DS18B20_Init()` | 初始化DWT定时器，复位总线并检测传感器存在 |
| `DS18B20_ResetPulse()` | 产生480μs复位脉冲，返回存在脉冲 |
| `DS18B20_WriteByte()` | 1-Wire写入一个字节(LSB first) |
| `DS18B20_ReadByte()` | 1-Wire读取一个字节(LSB first) |
| `DS18B20_StartConversion()` | 发送0x44转换命令，立即返回(非阻塞) |
| `DS18B20_ReadResult()` | 读取暂存器Byte0~1，计算温度=raw×0.0625 |
| `DS18B20_GetTemperature()` | 阻塞式：启动转换→750ms等待→读取结果 |

**1-Wire时序：** 复位480μs，写"1"=1μs低+60μs高，写"0"=60μs低+2μs高

---

### 5. oled.c — SSD1306 OLED显示驱动

| 函数/模块 | 说明 |
|-----------|------|
| `OLED_Init()` | SSD1306初始化序列：关闭显示→参数配置→开启显示→清屏 |
| `OLED_Clear()` | 清空1024字节显存缓冲区 |
| `OLED_Display()` | 通过I2C将缓冲区刷入SSD1306(8页×128列) |
| `OLED_ShowChar()` | 从字库取点阵绘制一个字符(Font6x8/Font8x16) |
| `OLED_ShowString()` | 字符串绘制，支持自动换行 |
| `OLED_ShowNum()` | 整数显示 |
| `OLED_ShowFloat()` | 浮点数显示 |
| `OLED_Printf()` | 格式化输出(Font6x8) |

**字库：** Font6x8[95][6]（小字体），Font8x16[95][16]（大字体）

---

### 6. key.c — 4×3矩阵键盘驱动

| 函数 | 说明 |
|------|------|
| `Key_Scan()` | 逐行扫描法：逐行置低→读列→去抖50ms→同键防重 |
| `Key_GetValue()` | 等同Key_Scan |

**按键映射：** `key_map[4][3]={{1,2,3},{4,5,6},{7,8,9},{0x0A,0,0x0B}}`

---

### 7. usart_com.c — USART1串口通信

| 函数 | 说明 |
|------|------|
| `UART_Init()` | 清空接收缓冲区与标志 |
| `UART_Send()` | HAL_UART_Transmit发送 |
| `UART_Printf()` | 格式化打印(vsnprintf封装) |
| `UART_ProcessRx()` | 轮询接收：检查RXNE标志→拼帧→\n结束→置标志 |

**数据上报格式：** `T:xx.x,SET:xx.x,PID:xx.x,HT:xx%,CL:xx%,RUN:xxx s`

---

### 8. rtc.c — RTC实时时钟

| 函数 | 说明 |
|------|------|
| `MX_RTC_Init()` | RTC配置：LSE 32.768kHz，1Hz计数 |
| `HAL_RTC_SetTime()` | 设置时间初值(上电从00:00:00开始) |
| `HAL_RTC_GetTime()` | 读取当前时间(每200ms调用) |

---

### 9. main.h — 系统全局头文件

| 定义 | 值 | 说明 |
|------|-----|------|
| `BUZZER_PIN` | GPIO_PIN_8 | 蜂鸣器PA8 |
| `TEMP_MIN` | 5.0f | 最低设定温度 |
| `TEMP_MAX` | 50.0f | 最高设定温度 |
| `TEMP_DEFAULT` | 37.0f | 默认目标温度 |
| `ALARM_TEMP_HIGH/LOW` | 2.0f | 报警阈值 |
| `CONTROL_CYCLE_MS` | 200 | 控制周期 |
| `USB_REPORT_CYCLE` | 1000 | 串口上报周期 |
| `SystemState` | enum | IDLE/RUNNING/SETTING/ALARM |

---

### 10. 上位机 Python 程序 (main.py)

| 类/函数 | 说明 |
|---------|------|
| `SensorData` | 串口数据解析类，解析T/SET/PID/HT/CL/RUN字段 |
| `TransferFunction` | FOPDT传递函数辨识(二点法)+Z-N参数建议+阶跃仿真 |
| `SerialReader` | 串口通信线程：连接/断开/发送/独立线程读取 |
| `IncubatorApp` | 主界面：Tkinter GUI，matplotlib实时曲线，参数设定，辨识结果，通信日志 |

**依赖：** pyserial, numpy, matplotlib
